# Hướng dẫn làm việc trong dự án Chat

## Mục tiêu học tập của người dùng

Người dùng xây dựng ứng dụng này để học backend Express. Khi viết hoặc sửa code
liên quan đến backend, **mỗi function chính chỉ cần một khối comment ngắn bằng tiếng Việt**
đặt trước hàm, mô tả chức năng của hàm. Không comment giải thích từng dòng.

Trước khi làm việc liên quan đến backend, đọc và áp dụng
[rules/backend-learning.md](rules/backend-learning.md).

Quy tắc này cũng áp dụng cho các đoạn tích hợp, gọi API backend ở frontend.

## Phong cách viết code

Code được viết mới hoặc chỉnh sửa phải dùng function/factory và functional component.
Không tự định nghĩa class cho logic ứng dụng.
